# ЧАСТЬ I. ОБЩИЕ ПОЛОЖЕНИЯ

## 1. Назначение и область применения

1.1. Настоящая инструкция устанавливает единый обязательный порядок работы оператора в программе Orda Point и в личном кабинете на сайте ordaops.kz.

1.2. Документ применяется ежедневно: при входе в программу, открытии смены, продаже товаров и услуг, оформлении возвратов и долгов, подаче заявок на склад, работе с игровыми зонами и закрытии смены.

1.3. Документ регулирует следующие блоки:

| Блок | Что регулирует |
|---|---|
| Устройство и вход | Настройка терминала, вход по паролю, вход по QR-коду, выбор точки |
| Смена | Открытие смены, стартовая касса, чек-листы, закрытие смены, сменный отчёт |
| Касса и продажи | Продажи, способы оплаты, скидки, лояльность, печать чека, возвраты, копия чека |
| Долги | Создание долга, окно удаления 15 минут, синхронизация |
| Склад | Заявки на инвентарь, статусы заявок, приём выданного товара |
| Залы и оборудование | Игровые зоны, сессии, тарифы, технические компенсации |
| Надёжность | Работа без интернета, очередь отправки, обновления программы |
| Ответственность | Штрафы, премии, зарплата, спорные ситуации, эскалация |

1.4. Незнание положений настоящей инструкции не освобождает сотрудника от ответственности. Критичные правила подтверждаются сотрудником в разделе «Обязательные материалы» личного кабинета (п. 20.5).

## 2. Термины и определения

| Термин | Значение |
|---|---|
| Orda Point | Десктопная программа оператора (терминал точки). В интерфейсе может отображаться как «Orda Point» / «Orda Control Point» |
| Токен устройства | Уникальный ключ, привязывающий конкретный терминал к конкретной точке. Выдаёт менеджер |
| Точка (компания) | Отдельная торговая/игровая точка: F16 Arena, F16 Extra, F16 Ramen |
| Смена | Рабочий период оператора от открытия до закрытия в программе |
| Стартовая касса | Сумма наличных, физически пересчитанная в кассовом ящике при приёме смены |
| ФАКТ | Фактическая сумма, собранная за смену, по формуле п. 16.4 |
| ИТОГ | ФАКТ за вычетом системного итога продаж; отрицательный ИТОГ = недостача |
| Тех. компенсация | Сумма, возвращённая или компенсированная клиенту из-за технической проблемы |
| Очередь отправки | Локальное хранилище операций, которые ещё не ушли на сервер (работа без интернета) |
| Чек-лист | Обязательная проверка (приём, обход, закрытие, онбординг) с фиксацией результата |
| Копия чека | Повторная печать ранее пробитого чека с крупной пометкой «КОПИЯ» |

## 3. Роли и ответственность

| Роль | Ответственность |
|---|---|
| Оператор / кассир | Корректно ведёт смену, принимает оплату, фиксирует проблемы, проходит чек-листы и закрывает смену без искажения данных |
| Старший смены | Контролирует работу операторов на смене, первым реагирует на инциденты |
| Менеджер точки | Выдаёт токен устройства, проводит онбординг, разбирает спорные штрафы, удаляет ошибочные долги после 15 минут, одобряет заявки склада |
| Владелец / управляющий | Утверждает правила, зарплату, доступы, тарифы и итоговую дисциплину точек |
| Технический ответственный | Разбирает сбои программы, оборудования, кассы, терминала оплаты, игровых зон и синхронизации |

**Разграничение ответственности за деньги.** За фактическое наличие денег в кассовом ящике и за корректность сумм, введённых при закрытии смены, отвечает оператор, закрывающий смену. Любое расхождение фиксируется в комментарии к смене до нажатия кнопки отправки, а не после.

## 4. Карта точек F16 и обязательные модули

> **КРИТИЧНО. Выбор точки после входа**
> Если к аккаунту привязано несколько точек, после входа программа предлагает выбор точки. Ошибка выбора точки приводит к неправильному учёту смены, кассы, долгов, склада и зарплаты.

| Точка | Что обслуживает оператор | Обязательные модули | Особые поля при закрытии |
|---|---|---|---|
| F16 Arena | Компьютерный зал, игровые зоны, сессии, посадка клиентов, техника | Смена; Чек-листы; Зал; Продажи; Долги; Заявки | Тех. компенсации; безнал; наличные; мелочь; комментарий по техсбоям |
| F16 Extra | PlayStation 5, Simracing, оборудование по ID, доп. развлекательная зона | Смена; Чек-листы; Зал; Продажи; Долги; Заявки | Тех. компенсации; безнал; наличные; мелочь; комментарий по оборудованию |
| F16 Ramen | Продажи кухни, напитков и товаров, склад, возвраты | Смена; Чек-листы; Продажи; Возвраты; Долги; Заявки | Итог системы продаж; безнал; наличные; мелочь; комментарий по остаткам и возвратам |

**4.1. Состав вкладок определяется настройками устройства.** Набор доступных разделов задаётся режимом точки и флагами устройства на сервере. Если нужной вкладки нет — это настройка, а не поломка: обратиться к менеджеру, а не искать обход.

**4.2. Критические ошибки точки**

| Ошибка | Почему опасно | Как правильно |
|---|---|---|
| Выбрана не та точка | Выручка, долги, склад и отчёт уходят не туда | Сразу сообщить менеджеру; не продолжать смену в неверной точке |
| Не внесён итог внешней системы | Невозможно сверить кассу с системой учёта | Внести итог соответствующей системы при закрытии |
| Не оставлен комментарий по инциденту | Невозможно доказать причину расхождения | Фиксировать событие в комментарии к смене |
| Долг создан без пояснения | Неясно, кто должен и за что | В комментарии указать клиента, товар/услугу и причину |
| Терминал выключен с непустой очередью | Операции не дошли до сервера | Дождаться отправки очереди (п. 15) |

# ЧАСТЬ II. ОБЩИЙ ПОРЯДОК РАБОТЫ

## 5. Устройство и вход в программу

### 5.1. Первичная настройка терминала (выполняет менеджер)

| Шаг | Действие |
|---|---|
| 1 | На экране входа открыть настройку устройства |
| 2 | Ввести адрес сервера: `https://ordaops.kz` |
| 3 | Ввести токен устройства, полученный у менеджера. Токен уникален для точки |
| 4 | Нажать «Проверить», затем «Сохранить» |

Токен устройства — служебный доступ. Передавать его посторонним, фотографировать и пересылать в мессенджерах запрещено.

### 5.2. Вход по логину и паролю

| Шаг | Действие |
|---|---|
| 1 | Выбрать вход оператора |
| 2 | Ввести логин и пароль |
| 3 | Нажать «Войти» |
| 4 | Если пароль временный — задать новый пароль и повторить его в поле «Повторите пароль» |
| 5 | Если точек несколько — выбрать свою точку |

### 5.3. Вход по QR-коду

| Шаг | Действие |
|---|---|
| 1 | Выбрать вход по QR — на экране терминала появится код |
| 2 | На телефоне открыть приложение Orda или сайт ordaops.kz и войти под своим аккаунтом |
| 3 | Подтвердить вход по QR в приложении/кабинете |
| 4 | Отсканировать код с экрана терминала — программа выполнит вход автоматически |
| 5 | Выбрать точку, если система предложила выбор |

Вход по QR недоступен без интернета. Если сети нет, используется вход по паролю при наличии сохранённой сессии.

### 5.4. Правила учётной записи

- Работать под чужой учётной записью запрещено. Все действия в системе привязываются к вошедшему оператору.
- При завершении работы выполнять выход из аккаунта, если терминалом пользуется другой сотрудник.
- Если сессия устарела, программа автоматически возвращает на экран входа — это норма, нужно войти заново.

## 6. Рабочий экран программы

### 6.1. Разделы (вкладки)

| Раздел | Назначение |
|---|---|
| Смена | Открытие и закрытие смены, сменный отчёт |
| Продажи | Продажа товаров и услуг, оплата, печать чека |
| Возвраты | Возврат товара по чеку смены |
| История | Продажи за последние 7 дней, печать копии чека |
| Долги (Сканер) | Оформление долга за товар |
| Заявки | Заявка на склад и история заявок |
| Зал | Игровые зоны и сессии (на точках с залом) |
| Мой кабинет | Смены, задачи, долги, обязательные материалы, профиль |

Набор вкладок одинаков на всех рабочих экранах и зависит только от настроек точки.

### 6.2. Служебные индикаторы

| Индикатор | Значение | Действие оператора |
|---|---|---|
| ⏳ N «в очереди» (жёлтый, вверху экрана) | N операций ждут отправки на сервер | Дождаться отправки; не выключать терминал |
| ⚠ N «требует внимания» (красный) | Сервер отклонил операции | Открыть очередь, прочитать причину, сообщить менеджеру |
| Баннер обновления (внизу справа) | Вышла новая версия программы | Скачать обновление и перезапустить программу в спокойный момент смены |

### 6.3. Настройки терминала

В настройках доступны: тема оформления, размер текста, звуки, вид кассы и экран клиента (второй монитор). Настройки влияют только на внешний вид терминала и не меняют учёт. Экран клиента включается при наличии второго монитора.

## 7. Открытие смены

| Шаг | Действие | Контроль |
|---|---|---|
| 1 | Запустить Orda Point | Программа открывается без ошибки |
| 2 | Войти по паролю или QR | Оператор видит своё имя |
| 3 | Выбрать точку | Точка соответствует фактическому месту работы |
| 4 | Физически пересчитать наличные в кассовом ящике | Сумма пересчитана, а не принята «со слов» |
| 5 | Ввести стартовую кассу | Введена фактическая сумма |
| 6 | Выбрать тип смены: ☀️ Дневная или 🌙 Ночная | Соответствует фактическому графику |
| 7 | Открыть смену | Смена активна |
| 8 | Пройти чек-лист приёма/открытия смены | Чек-лист завершён |

> **ВАЖНО. Стартовая касса**
> Стартовая касса — это сумма наличных, которую оператор физически пересчитал при приёме смены. Вводить сумму «примерно», «как вчера» или со слов сменщика запрещено. После открытия смены поле стартовой кассы блокируется: значение зафиксировано и изменить его самостоятельно нельзя.

**7.1. Ошибки при открытии смены**

| Сообщение / ситуация | Действие оператора |
|---|---|
| Не пройден онбординг | Сообщить менеджеру; пройти вводный чек-лист онбординга |
| Предыдущая смена ещё открыта | Найти предыдущего оператора и закрыть его смену. Открывать вторую смену поверх незакрытой запрещено |
| Требуется указать стартовую кассу | Пересчитать наличные и ввести сумму |
| Нет связи с сервером | Работать по кэшу; операции уйдут в очередь (п. 15) |

## 8. Чек-листы

### 8.1. Виды чек-листов

| Вид | Когда проходить | Поведение системы |
|---|---|---|
| Приём смены / пересменка | До принятия ответственности за смену | Может блокировать работу до прохождения |
| Открытие | После открытия смены | Фиксирует стартовое состояние точки |
| Периодический обход | По расписанию точки (типовое значение — каждые 2 часа) | Напоминает проверить зал, технику, чистоту и остатки |
| Закрытие | Перед закрытием смены | Блокирует закрытие смены до прохождения |
| Онбординг | Перед первой сменой нового сотрудника | Блокирует первую смену до прохождения |

Чек-лист с пометкой «Блокирует смену» обязателен: пока он не завершён, соответствующее действие недоступно.

### 8.2. Порядок прохождения

| Шаг | Действие |
|---|---|
| 1 | Открыть раздел «Чек-листы» |
| 2 | Выбрать нужный чек-лист и начать его |
| 3 | По каждому пункту дать ответ: отметка «выполнено», текст, число или выбор — в зависимости от пункта |
| 4 | Если пункт помечен как фото-доказательство — приложить фото. Без фото такой чек-лист завершить нельзя |
| 5 | По проблемному пункту оставить комментарий с сутью проблемы |
| 6 | Завершить чек-лист |

Пункты с пометкой «обязательно» должны быть заполнены полностью — незаполненные пункты система перечислит при попытке завершения.

> **ВАЖНО. Автоматические штрафы и премии**
> К пункту чек-листа может быть привязана сумма штрафа или премии. Проваленный обязательный пункт создаёт штраф, выполненный премируемый пункт — начисление. Суммы задаёт руководство точки; примеры: зал не убран — штраф, полная посадка зала — премия.

**8.3. Запрещено:** отмечать пункты «за глаза», не выходя в зал; прикладывать старые фотографии; проходить чек-лист заранее «на всю смену вперёд». Это нарушение с последствиями по п. 21.

## 9. Продажи через кассу

### 9.1. Порядок продажи

| Шаг | Действие |
|---|---|
| 1 | Открыть раздел «Продажи» |
| 2 | Отсканировать штрихкод или найти товар по названию/артикулу — товар добавляется в чек |
| 3 | Проверить количество и цену в чеке |
| 4 | При необходимости применить скидку: ручной процент или промокод |
| 5 | При наличии программы лояльности — найти клиента и, при необходимости, списать бонусы |
| 6 | При необходимости добавить комментарий к продаже |

## 15. Работа без интернета

15.1. При потере связи программа продолжает работать: витрина и каталог берутся из локального кэша, а операции (продажи, возвраты, долги, заявки, сменный отчёт) сохраняются в очередь отправки.

15.2. Поведение очереди:

| Состояние | Значение | Действие оператора |
|---|---|---|
| ⏳ Ждут отправки | Связь ещё не восстановилась | Продолжать работу; программа отправит операции сама |
| ⚠ Требует внимания | Сервер отклонил операцию | Открыть очередь, прочитать причину, сообщить менеджеру |
| «Все операции отправлены ✓» | Очередь пуста | Терминал можно выключать |

> **КРИТИЧНО. Не выключать терминал с непустой очередью**
> Пока в очереди есть операции, программу и компьютер выключать нельзя: данные ещё не на сервере. Дождаться сообщения о пустой очереди либо согласовать действия с менеджером.

15.3. Вход по QR и часть серверных операций без интернета недоступны. Это ожидаемое поведение, а не поломка.

## 16. Закрытие смены и кассовая дисциплина

### 16.1. Подготовка

| Контроль | Что сделать |
|---|---|
| Чек-лист закрытия | Пройти полностью — без него смена не закрывается |
| Терминал оплаты | Снять итоговый отчёт по терминалу |
| Наличные | Пересчитать купюры в кассовом ящике |
| Мелочь | Пересчитать отдельно |
| Зал | Завершить или передать активные сессии |
| Очередь | Убедиться, что операции отправлены |
| Инциденты | Собрать факты: техсбои, пересадки, конфликты, расхождения |

### 16.2. Поля формы закрытия

| Поле | Что вводить |
|---|---|
| Дата | Дата смены |
| Смена | ☀️ Дневная или 🌙 Ночная |
| Наличные | Сумма купюр в кассе (без мелочи) |
| Мелочь | Сумма монет отдельно |
| Безналичная оплата (POS) | Итог по терминалу за смену |
| Безнал до 00:00 / после 00:00 | Только для ночной смены при включённом разделении по суткам |
| Тех. компенсации | Сумма компенсаций, выданных за смену |
| Старт кассы | Подставляется автоматически из открытия смены; правке не подлежит |
| Итог системы продаж | Подставляется автоматически из раздела «Продажи»; на точках с внешней системой учёта вводится вручную |
| Комментарий | Все существенные события смены |

> **ВАЖНО. Порядок ввода наличных**
> Сначала вводится мелочь, затем наличные: мелочь вычитается из суммы наличных, чтобы в отчёт ушли только купюры.

### 16.3. Ночная смена

При включённом разделении по суткам безналичная выручка ночной смены вводится двумя суммами: до 00:00 и после 00:00. В сумме они дают общий безналичный итог смены. Разделение нужно для корректного учёта суток и отчётности.

### 16.4. Формула расчёта

```
ФАКТ = Наличные + Мелочь + Безнал (POS) + Тех. компенсации − Старт кассы

ИТОГ = ФАКТ − Итог системы продаж
```

| Значение ИТОГ | Что означает |
|---|---|
| 0 или около нуля | Касса сходится |
| Больше нуля | Излишек — требует комментария |
| Меньше нуля | **Недостача** — требует комментария и уведомления менеджера до закрытия смены |

Программа показывает формулу построчно и подписывает состояние отчёта. Закрывать смену с недостачей молча запрещено.

### 16.5. Отправка отчёта

| Шаг | Действие |
|---|---|
| 1 | Проверить все суммы и формулу |
| 2 | Заполнить комментарий, если были инциденты или расхождения |
| 3 | Отправить отчёт (сочетание клавиш Ctrl+Enter) |
| 4 | Подтвердить закрытие смены в окне подтверждения |
| 5 | При необходимости распечатать сменный отчёт |
| 6 | Убедиться, что очередь отправки пуста |

Если связи нет, отчёт попадает в очередь и будет отправлен автоматически при восстановлении интернета.

### 16.6. Финальная проверка перед закрытием

| № | Вопрос | Ответ должен быть |
|---|---|---|
| 1 | Точка выбрана правильно? | Да |
| 2 | Чек-лист закрытия завершён? | Да |
| 3 | Наличные и мелочь пересчитаны физически? | Да |
| 4 | Безналичный итог совпадает с отчётом терминала? | Да |
| 5 | Все сессии зала завершены или переданы? | Да / не применимо |
| 6 | Итог внешней системы внесён? | Да / не применимо |
| 7 | Все долги, возвраты и компенсации оформлены? | Да |
| 8 | Есть комментарий по расхождениям и инцидентам? | Да / инцидентов не было |
| 9 | Очередь отправки пуста? | Да |

**20.5. Подтверждение обязательных материалов**

| Шаг | Действие |
|---|---|

> **ВАЖНО. Критичные правила**
> Если сотрудник не подтвердил критичное правило, ссылаться на «не знал» в спорной ситуации нельзя. Подтверждение — это фиксация ознакомления, а не формальность.

## 21. Зарплата, штрафы и премии

| Тип | Примеры |
|---|---|
| Начисляется | Ставка за смену; премия за порог выручки; премия за полную посадку зала; премия за пункт чек-листа |
| Вычитается | Штраф по чек-листу; штраф-инцидент от менеджера; долг оператора; материальная ответственность |
| Итог | Базовая сумма + премии − штрафы − долги |

Конкретные суммы ставок, премий и штрафов устанавливаются руководством точки и могут отличаться по точкам и типам смен.

> **ИНФО. Спорный штраф**
> Если штраф кажется несправедливым, оператор обращается к менеджеру. Менеджер переводит штраф в статус оспаривания или аннулирует его при наличии оснований. Самостоятельное «исправление» данных в программе запрещено и рассматривается как отдельное нарушение.

## 22. Типовые проблемы и эскалация

| Блок | Проблема | Решение |
|---|---|---|
| Вход | Ошибка при входе | Проверить интернет; при наличии связи — сообщить менеджеру |
| Вход | Выкинуло на экран входа | Сессия истекла — войти заново |
| Смена | Не открывается: не пройден онбординг | Сообщить менеджеру, пройти онбординг |
| Смена | Не открывается: смена уже открыта | Найти предыдущего оператора и закрыть его смену |
| Смена | Не закрывается: не пройден чек-лист | Завершить обязательный чек-лист закрытия |
| Чек-лист | Чек-лист не появляется | Перезапустить программу; если не помогает — менеджеру |
| Долги | Введена неверная сумма | Удалить свою запись в течение 15 минут и оформить заново |
| Долги | Запись не удаляется | Окно 15 минут истекло — обратиться к менеджеру |
| Касса | Терминал оплаты не проводит платёж | Зафиксировать и немедленно сообщить менеджеру; не проводить оплату «мимо кассы» |
| Оборудование | Проблема с ПК / PS5 / Simracing | Зафиксировать ID или номер станции и суть проблемы; сообщить менеджеру |
| Программа | Белый экран, зависание | Закрыть и открыть программу заново; смена и отправленные данные не теряются |
| Связь | Нет интернета | Продолжать работу; следить за очередью отправки (п. 15) |
| Очередь | ⚠ «требует внимания» | Открыть очередь, прочитать причину отклонения, сообщить менеджеру |
| Обновление | Баннер обновления | Обновиться в спокойный момент смены, не во время очереди клиентов |

### 22.1. Куда обращаться

| Ситуация | Адресат |
|---|---|
| Технические проблемы с программой | Менеджер точки |
| Проблема с оборудованием | Менеджер точки, с фиксацией в программе |
| Расхождение по кассе | Менеджер немедленно, до закрытия смены, с комментарием в отчёте |
| Несправедливый штраф | Менеджер точки |
| Ошибки в расчёте зарплаты | Менеджер / владелец через ordaops.kz |
| Утеря доступа, подозрительный запрос доступа | Менеджер немедленно |
