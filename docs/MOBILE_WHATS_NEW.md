# Что появилось в приложении и где это нажать

Список для проверки: каждый пункт — путь до кнопки. Если кнопки нет, значит не
выдано право, оно указано в скобках.

Владельческие разделы открываются через **«Разделы»** на телефоне и через
боковую панель на планшете.

---

## Оператор

| Что | Где нажать |
|---|---|
| **Как я работаю** — оценка за месяц, сильные и слабые стороны, доплата за качество | Профиль → «Как я работаю» |
| **Статьи с таблицами** читаются, а не склеиваются в кашу | Профиль → База знаний → любая статья |
| **Кнопка «Прочитал и понял»** закреплена снизу, а не спрятана в конце текста | там же, внутри статьи |
| **Крупный шрифт** — меняется прямо в листе настроек | Профиль → значок человека → Настройки аккаунта |
| **Быстрые действия**: «Смена», «Продажа», «Ревизия» | долгое нажатие на иконку приложения |
| **Живая активность смены** на экране блокировки | появится в следующей сборке, на живом устройстве |
| **Отложенные действия** — полоса «сохранено на устройстве» | при обрыве связи: чек-лист, подтверждение регламента, ответ на задачу |

## Деньги

| Что | Где нажать | Право |
|---|---|---|
| **Аванс, премия, штраф** | Зарплата → строка оператора | `salary.create_advance`, `salary.create_adjustment` |
| **Долг оператора погашен** | там же, отдельной кнопкой внизу листа | `salary.mark_debt_paid` |
| **Расчёт за неделю в Telegram** | там же | `salary.send_telegram` |
| **Долг с точки погашен** | Долги с точки → строка непогашенного долга | `point-debts.mark_paid` |

## Склад

| Что | Где нажать | Право |
|---|---|---|
| **Перенос на витрину и возврат на склад** | Витрина → строка товара | `store-showcase.move`, `store-showcase.return_to_warehouse` |
| **Новая заявка со склада на витрину** | Заявки → «плюс» | `store-requests.create` |
| **Приёмка с фотографии накладной** | Приёмки → новая приёмка → «Сфотографировать» | `store-receipts.ai_parse` |
| **Отмена приёмки** | Приёмки → открыть приёмку → «Отменить приёмку» | `store-receipts.cancel` |
| **Отмена списания** | Списания → открыть списание → «Отменить списание» | `store-writeoffs.cancel` |
| **Новый поставщик** | Поставщики → «плюс» | `store-suppliers.create` |

|---|---|---|
| **Команда: стаж и сроки документов** | Разделы → Команда | `operator-analytics.view` |
| **Позвонить оператору** | Команда → карточка человека → телефон | — |

## Аттестация

## Клиенты и точки

| Что | Где нажать | Право |
|---|---|---|
| **Новый клиент** (карта сканируется камерой) | Клиенты → «плюс» | `customers.create` |
| **Начислить или списать баллы** | Клиенты → карточка → «Баллы» | `customers.adjust_points` |

## Разное

| Что | Где |
|---|---|
| **Поиск по разделам и действиям** | Разделы → строка поиска (ищет и по действиям внутри) |
| **Эффективность продавцов** — кому сколько доплатить | Разделы → Эффективность продавцов |
| **Кнопки в уведомлениях** — «Одобрить» у расхода, «Ответить» у сообщения | потяните уведомление вниз |
| **Face ID при открытии** | экран входа, спрашивается сам |
| **Не получается войти** | экран входа, внизу формы |

## Чего ещё нет

По разбору `docs/MOBILE_ACTION_TRIAGE.md`: 20 действий из тех, что просятся на
телефон, ещё не сделано — товар в каталоге, сотрудник, смена в
расписании, заявка поставщику, цель, статья базы знаний, реклама на витрине.

Работа за столом — выгрузки, печать, импорт, правила зарплаты, роли — на
телефон не переносится намеренно.
