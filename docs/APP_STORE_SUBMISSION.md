# Публикация Orda в App Store

Что уже сделано в коде и что нужно заполнить руками. Порядок важен: сначала
сервер, потом сборка, потом метаданные.

## 0. Перед всем — выкатить сайт

Приложение ходит на `www.ordaops.kz`. Пока сервер не обновлён, часть разделов
отвечает «появится после обновления сайта», а ревьюер увидит пустые экраны и
отклонит сборку.

- [ ] `git push` — сейчас в `main` локально накопились коммиты, которых нет на
      Vercel. Без них не работают: удаление аккаунта (`/api/me/account`),
      правка своих данных (`/api/me/profile`), контакты для личных сообщений
      (`/api/direct-messages/contacts`), ОПиУ (исправленные даты).
- [ ] Применить `supabase/migrations/20260811_team_chat_organization_backfill.sql`
      в SQL Editor — иначе командный чат показывает сообщения чужих организаций.
- [ ] Проверить переменные APNs в Vercel: `APNS_KEY_ID`, `APNS_TEAM_ID`,
      `APNS_PRIVATE_KEY`, `APNS_BUNDLE_ID = kz.ordaops.apple`.
      `APNS_ENVIRONMENT` не задавать — по умолчанию `production`, и это то, что
      нужно для сборки из App Store.

## 1. Что уже готово в приложении

| Требование Apple | Где |
|---|---|
| Удаление аккаунта из самого приложения | «Аккаунт» → «Удалить аккаунт» |
| Ссылка на политику конфиденциальности | «Аккаунт» → «Документы» |
| Описание доступа к камере и Face ID | `Orda-Info.plist` |
| Иконка 1024×1024 без альфа-канала | `Assets.xcassets/AppIcon.appiconset` |
| Экспортное соответствие | `ITSAppUsesNonExemptEncryption = false` |
| Боевой APNs в релизной сборке | `APS_ENVIRONMENT` в настройках сборки |
| Поддержка iPhone и iPad | `TARGETED_DEVICE_FAMILY = 1,2` |

Версия — `1.0`, сборка — `1` (`MARKETING_VERSION` / `CURRENT_PROJECT_VERSION` в
`apple/Orda.xcodeproj`). Каждая повторная загрузка требует новой сборки:
увеличивать `CURRENT_PROJECT_VERSION`.

## 2. Подписание

- [ ] В `apple/Config.xcconfig` заполнить `DEVELOPMENT_TEAM` — Team ID из
      Apple Developer.
- [ ] В App Store Connect создать приложение с bundle id `kz.ordaops.apple`.
- [ ] В Certificates → Identifiers включить у идентификатора **Push
      Notifications**, иначе архив не подпишется с `aps-environment`.
- [ ] Xcode → Product → Archive (схема Orda, конфигурация Release,
      устройство «Any iOS Device»), затем Distribute App → App Store Connect.

## 3. Метаданные — готовый текст

**Название:** Orda
**Подзаголовок:** Управление клубом и точками продаж
**Категория:** Бизнес (вторая — Финансы)
**Возрастной рейтинг:** 4+
**Цена:** бесплатно (доступ даёт подписка организации на сайте)

**Ключевые слова:** клуб, точка продаж, смены, выручка, склад, зарплата,
операторы, отчёты, касса, инвентаризация

**URL поддержки:** https://www.ordaops.kz
**URL политики конфиденциальности:** https://www.ordaops.kz/privacy

**Описание:**

> Orda — рабочее место владельца и управляющего точкой продаж: компьютерного
> клуба, магазина, кофейни.
>
> Смены и выручка. Видно, кто на смене прямо сейчас, сколько наличных в кассе,
> какая выручка с начала дня и чем она отличается от вчерашней.
>
> Деньги. Доходы и расходы заводятся с телефона — с фотографией чека. Отчёт о
> прибылях и убытках собирается сам, ручные строки можно поправить.
>
> Склад. Приёмка от поставщика, списания, ревизия, заявки со склада на витрину
> и решения по ним.
>
> Люди. Оформление оператора с выдачей доступов, зарплатные ведомости, задачи,
> инциденты, командный чат и личные сообщения.
>
> Для работы нужна учётная запись в системе Orda: её выдаёт владелец
> организации. Приложение — часть сервиса ordaops.kz.

**Что нового в этой версии** (для 1.0): «Первая версия.»

## 4. Данные для ревью (App Review Information)

Ревьюер не сможет ничего посмотреть без учётной записи — приложение закрыто
целиком. Без демо-доступа отклонение гарантировано.

- [ ] Sign-in required: **Yes**
- [ ] Demo account: завести отдельного пользователя с ролью владельца в
      тестовой организации с наполненными данными (смены, товары, расходы).
      Логин и пароль вписать в поля Demo Account.
- [ ] Notes — текст на английском:

> Orda is a B2B tool for owners of gaming clubs and small retail points in
> Kazakhstan. Access is granted by the point owner; the demo account above
> belongs to a test organization with sample data.
>
> Account deletion: Account tab (person icon in the top bar, or the "Профиль"
> tab on iPhone) → "Удалить аккаунт".
>
> The app language is Russian: the product is sold in Kazakhstan only.

## 5. Ярлыки конфиденциальности (App Privacy)

Что приложение реально отправляет на сервер:

| Категория | Данные | Связано с пользователем | Для отслеживания |
|---|---|---|---|
| Contact Info | почта, телефон, Telegram id | да | нет |
| User Content | фотографии чеков и вложения в чат, сообщения | да | нет |
| Identifiers | идентификатор учётной записи, токен устройства для push | да | нет |

Аналитики, рекламы и трекинга нет: раздел Tracking — «No». Данные третьим
лицам в рекламных целях не передаются.

## 6. Снимки экрана

Обязательны два набора; остальные размеры Apple масштабирует сам.

- iPhone 6.9″ — 1320×2868 (симулятор iPhone 17 Pro Max)
- iPad 13″ — 2064×2752 (симулятор iPad Pro 13-inch)

Снимать на реальных данных демо-организации. Что показывать: «Обзор» с
выручкой, смены, доходы и расходы, склад, зарплату.

Снять с симулятора:

```
xcrun simctl io "iPhone 17 Pro Max" screenshot ~/Desktop/orda-1.png
```

## 7. После первой публикации

- [ ] Убрать временные ограничения в `NativeSection` (их показывает
      `node scripts/audit-native-gates.mjs`) — они стоят там, пока сервер не
      обновлён.
- [ ] Проверить, что push доходит на боевую сборку: новость из «Ленты» должна
      прийти уведомлением на устройство.
