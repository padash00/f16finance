# Публикация Orda в App Store

Что уже сделано в коде и что нужно заполнить руками. Порядок важен: сначала
сервер, потом подпись, потом метаданные.

## 0. Перед всем — миграции и сервер

Приложение ходит на `www.ordaops.kz`. Всё, что накопилось в `main`, выкачено
автоматически, но две вещи применяются руками.

- [x] `supabase/migrations/20260811_team_chat_organization_backfill.sql` —
      организация у старых сообщений чата.
- [x] `supabase/migrations/20260812_exam_attempt_reminded_on.sql` — отметка
      напоминания об экзамене.
- [ ] `supabase/migrations/20260812_direct_message_blocks.sql` — блокировка
      собеседника. **Без неё блокировка не работает, а это требование
      App Store (пункт 1.2).**
- [ ] Переменные APNs в Vercel: `APNS_KEY_ID`, `APNS_TEAM_ID`,
      `APNS_PRIVATE_KEY`, `APNS_BUNDLE_ID = kz.ordaops.apple`.
      `APNS_ENVIRONMENT` не задавать — по умолчанию `production`, это и нужно
      для сборки из App Store.

## 1. Что уже готово в приложении

| Требование Apple | Где |
|---|---|
| Удаление аккаунта из приложения (5.1.1v) | «Аккаунт» → «Удалить аккаунт» |
| Жалоба на сообщение (1.2) | долгое нажатие на сообщение → «Пожаловаться» |
| Блокировка собеседника (1.2) | личная переписка → «⋯» → «Заблокировать» |
| Фильтр недопустимого (1.2) | проверка текста на сервере + ночная проверка ИИ |
| Ссылка на политику конфиденциальности | «Аккаунт» → «Документы» |
| Манифест конфиденциальности | `apple/Orda/PrivacyInfo.xcprivacy` |
| Описания камеры, микрофона, Face ID | `apple/Orda-Info.plist` |
| Иконка 1024×1024 без альфа-канала | `Assets.xcassets/AppIcon.appiconset` |
| Экспортное соответствие | `ITSAppUsesNonExemptEncryption = false` |
| Боевой APNs в релизной сборке | `APS_ENVIRONMENT` в настройках сборки |
| Поддержка iPhone и iPad | `TARGETED_DEVICE_FAMILY = 1,2` |
| Вход через Apple (4.8) | не требуется: сторонних входов нет |
| Покупки внутри приложения (3.1.1) | не требуется: подписку в приложении не продаём, платёжных ссылок нет |

Версия — `1.3.1`, сборка — `6`.

Повторная загрузка под тем же номером версии не пройдёт: как только версия
одобрена, Apple требует поднять `MARKETING_VERSION`, а не только номер сборки —
иначе выгрузка падает с кодом 90062. Каждая повторная загрузка требует новой сборки:
увеличивать `CURRENT_PROJECT_VERSION`.

**Иконка — без альфа-канала.** App Store не принимает иконку с прозрачностью:
сборка загружается, но на странице вместо знака остаётся серый квадрат и
обработка не проходит. Генератор иконок рисует в контексте `noneSkipLast`
именно поэтому — проверить можно так: `sips -g hasAlpha icon-1024.png`.

Релизная сборка собирается без предупреждений — проверено
`xcodebuild -configuration Release`.

## 2. Подпись — ваша часть

- [ ] **Team ID** в `apple/Config.xcconfig`, строка `DEVELOPMENT_TEAM`. Сейчас
      пустая, без неё архив не подписать.
- [ ] **App ID** `kz.ordaops.apple` в Certificates → Identifiers, и в нём
      включить **Push Notifications**. Иначе архив не подпишется с правом на
      уведомления.
- [ ] **APNs-ключ (.p8)**: Keys → Apple Push Notifications service, если ещё
      не заводили.
- [ ] Запись приложения в App Store Connect с тем же bundle id.
- [ ] Agreements, Tax, and Banking — статус Active. Для бесплатного приложения
      достаточно Free Apps agreement, но без него публикации не будет.
- [ ] Xcode → Product → Archive (схема Orda, конфигурация Release, устройство
      «Any iOS Device») → Distribute App → App Store Connect.

## 3. Метаданные — готовый текст

**Название:** Orda
**Подзаголовок:** Управление клубом и точками продаж
**Категория:** Бизнес (вторая — Финансы)
**Возрастной рейтинг:** 4+
**Цена:** бесплатно (доступ даёт подписка организации на сайте)

**Ключевые слова:** клуб, точка продаж, смены, выручка, склад, зарплата,
операторы, отчёты, касса, инвентаризация

**URL поддержки:** https://www.ordaops.kz
**URL политики конфиденциальности:** https://www.ordaops.kz/privacy

**Описание:**

> Orda — рабочее место владельца и управляющего точкой продаж: компьютерного
> клуба, магазина, кофейни.
>
> Смены и выручка. Видно, кто на смене прямо сейчас, сколько наличных в кассе,
> какая выручка с начала дня и чем она отличается от вчерашней. Смену можно
> открыть и закрыть с телефона — с пересчётом кассы и отчётом.
>
> Деньги. Доходы и расходы заводятся с телефона, с фотографией чека. Отчёт о
> прибылях и убытках собирается сам: выручка, себестоимость, EBITDA, чистая
> прибыль — с долей каждой статьи и разбором по месяцам.
>
> Склад. Приёмка от поставщика, списания, ревизия, заявки со склада на витрину
> и решения по ним.
>
> Люди. Оформление оператора с выдачей доступов, зарплата с разбором по сменам,
> задачи с обсуждением, аттестация по регламентам точки, командный чат и личные
> сообщения — с фотографиями и голосовыми.
>
> Для работы нужна учётная запись в системе Orda: её выдаёт владелец
> организации. Приложение — часть сервиса ordaops.kz.

**Что нового в этой версии** (для 1.0): «Первая версия.»

> Orda is a B2B tool for owners of gaming clubs and small retail points in
> Kazakhstan. Access is granted by the point owner; the demo account above

>
> Account deletion: Account (person icon in the top bar, or the "Профиль" tab

>

## 5. Ярлыки конфиденциальности (App Privacy)

Совпадают с `PrivacyInfo.xcprivacy`:

| Категория | Данные | Связано с пользователем | Для отслеживания |
|---|---|---|---|
| Contact Info | почта, телефон, имя | да | нет |
| User Content | сообщения, фотографии чеков и вложения, голосовые | да | нет |
| Identifiers | идентификатор учётной записи, токен устройства | да | нет |

Аналитики, рекламы и трекинга нет: раздел Tracking — «No».

## 6. Снимки экрана

Обязательны два набора; остальные размеры Apple масштабирует сама.

- iPhone 6.9″ — 1320×2868 (симулятор iPhone 17 Pro Max)
- iPad 13″ — 2064×2752 (симулятор iPad Pro 13-inch)

Снимаются одной командой, когда на симуляторе выполнен вход:

```
apple/Tools/screenshots.sh "iPhone 17 Pro Max" ~/Desktop/orda-shots/iphone
apple/Tools/screenshots.sh "iPad Pro 13-inch (M5)" ~/Desktop/orda-shots/ipad
```

Скрипт обходит разделы сам (обзор, смены, доходы, расходы, ОПиУ, склад,
зарплата, задачи) и ставит часы 9:41 с полной батареей.

**Важно: входить нужно владельцем одной точки, а не суперадмином** — у
суперадмина на экране вкладки «Платформа» и список чужих организаций.
