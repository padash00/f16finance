# Карты лояльности в Apple Wallet — что нужно сделать вам

Сервер уже умеет выпускать карты для Google Wallet (`lib/server/google-wallet.ts`).
Для Apple половина работы такая же — номер карты, имя, бонусы у нас есть, — но
подписывать пропуск нужно сертификатом Apple. Выпустить его может только
владелец аккаунта разработчика, из кода это не делается.

Ниже всё, что нужно сделать один раз. Занимает минут двадцать. Как появятся
переменные окружения — серверную часть и кнопку «Добавить в Apple Wallet»
я допишу.

---

## 1. Завести Pass Type ID

1. Откройте <https://developer.apple.com/account/resources/identifiers/list/passTypeId>
2. Кнопка **+** → выберите **Pass Type IDs** → Continue.
3. Заполните:
   - **Description**: `Orda Loyalty`
   - **Identifier**: `pass.kz.ordaops.loyalty`
     (префикс `pass.` обязателен; идентификатор потом не меняется)
4. Continue → Register.

## 2. Сделать запрос на сертификат (CSR)

Это файл, которым вы просите Apple выпустить сертификат. Делается на Mac.

1. Откройте **Связка ключей** (Keychain Access).
2. Меню **Связка ключей** → **Ассистент сертификации** → **Запросить сертификат
   у бюро сертификации…**
3. Заполните:
   - **Адрес почты пользователя**: ваша почта разработчика
   - **Общее имя**: `Orda Loyalty`
   - **Адрес почты БС**: оставьте пустым
   - Отметьте **Сохранён на диске**
4. Сохраните файл `CertificateSigningRequest.certSigningRequest`.

Важно: приватный ключ при этом остаётся в связке ключей на **этом** Mac. Если
делать сертификат на одном компьютере, а экспортировать на другом — ничего не
выйдет.

## 3. Выпустить сертификат

1. Вернитесь на страницу Pass Type ID, откройте созданный `pass.kz.ordaops.loyalty`.
2. **Create Certificate** → загрузите файл CSR из шага 2 → Continue.
3. Скачайте `pass.cer`.
4. Двойным щелчком установите его в связку ключей.

## 4. Экспортировать в `.p12`

1. В связке ключей раздел **Мои сертификаты**.
2. Найдите `Pass Type ID: pass.kz.ordaops.loyalty`.
3. Правой кнопкой → **Экспортировать** → формат **Personal Information Exchange (.p12)**.
4. Задайте пароль и запомните его — он понадобится в шаге 6.
5. Сохраните как `orda-pass.p12`.

## 5. Скачать промежуточный сертификат Apple

Пропуск подписывается цепочкой, и без промежуточного сертификата Wallet его не
примет.

1. Откройте <https://www.apple.com/certificateauthority/>
2. Скачайте **Worldwide Developer Relations — G4** (`AppleWWDRCAG4.cer`).

## 6. Превратить в текстовый вид для сервера

Vercel хранит переменные строками, поэтому сертификаты нужно перевести из
двоичного вида в PEM. Выполните в Терминале в папке со скачанными файлами:

```sh
# Сертификат
openssl pkcs12 -legacy -in orda-pass.p12 -clcerts -nokeys -out pass-cert.pem

# Приватный ключ (спросит пароль от .p12, затем задайте пароль ключа)
openssl pkcs12 -legacy -in orda-pass.p12 -nocerts -out pass-key.pem

# Промежуточный сертификат Apple
openssl x509 -inform der -in AppleWWDRCAG4.cer -out wwdr.pem
```

Если `openssl` ругается на `-legacy`, уберите этот флаг: он нужен только новым
версиям OpenSSL для старого формата `.p12`.

## 7. Прислать мне значения

Понадобятся четыре переменные окружения. Добавьте их в Vercel
(**Settings → Environment Variables**) — или пришлите, и я подставлю:

| Переменная | Что положить |
|---|---|
| `APPLE_WALLET_PASS_TYPE_ID` | `pass.kz.ordaops.loyalty` |
| `APPLE_WALLET_TEAM_ID` | `YRA24D32N2` |
| `APPLE_WALLET_CERT` | содержимое `pass-cert.pem` целиком |
| `APPLE_WALLET_KEY` | содержимое `pass-key.pem` целиком |
| `APPLE_WALLET_KEY_PASSWORD` | пароль ключа из шага 6 |
| `APPLE_WALLET_WWDR` | содержимое `wwdr.pem` целиком |

PEM — это текст между строками `-----BEGIN …-----` и `-----END …-----`
включительно. Переносы строк сохраняйте.

**Файлы `.p12`, `.pem` и пароль в репозиторий не кладите.** Приватный ключ
пропуска — это право выпускать карты от имени вашей организации.

## Что сделаю я, когда переменные появятся

1. `lib/server/apple-wallet.ts` — сборка и подпись `.pkpass`: манифест,
   подпись PKCS#7, архив.
2. Роут `GET /api/wallet/apple/[cardId]` — отдаёт готовый пропуск по карте
   клиента, с проверкой прав и организации.
3. Кнопка **«Добавить в Apple Wallet»** в карточке клиента: на iPhone —
   системное окно PassKit, на сайте — ссылка на скачивание.
4. Обновление карты при изменении баланса бонусов — через тот же APNs, что уже
   настроен для уведомлений.

Отдельного разрешения в приложении для добавления пропуска не нужно, и на
проверку в App Store это не влияет.

## Сроки и деньги

Сертификат бесплатный, входит в подписку разработчика. Живёт год —
за месяц до конца Apple пришлёт письмо, продление это те же шаги 2–6.
