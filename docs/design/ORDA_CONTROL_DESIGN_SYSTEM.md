# ORDA CONTROL — дизайн-система

Один визуальный язык для сайта, веб-панели и приложения (iOS/iPad/Mac) всех
ролей: владелец, суперадмин, администратор, оператор, кассир, сотрудник.
Меняется только вид — логика, права, маршруты, API и расчёты те же.

Бренд: «Your business, in control.» / «Бизнес под контролем.»

## Знак и логотип

- Знак — круглое «O»: кольцо + кобальтовый сегмент справа сверху.
  Геометрия (поле 100×100): кольцо r=29, толщина 15; сегмент r=29, толщина 19,
  от −112° до −8°, круглые концы.
- Логотип: знак вместо «O» + «RDA» (жирность 800), под ним CONTROL разрядкой 0.62em.
- Код: `components/brand/orda-control-mark.tsx` (сайт),
  `apple/OrdaUI/Sources/OrdaUI/Brand/OrdaControlMark.swift` (приложение),
  `apple/Tools/GenerateAppIcon.swift` (иконка).
- Знак не превращать в индикатор загрузки. Для загрузки — скелеты.

## Типографика

- Приложение: SF Pro (системный). Сайт: Inter (`--font-sans`).
- Заголовок экрана 28–30/700, раздела 19–20/700, тело 15–16/400–500,
  подписи 12–13/400, цифры — моноширинные (tabular), округлая гарнитура для сумм.
- Разрядка капсом — только в бренд-подписях (CONTROL), не в интерфейсе.

## Форма

- Радиусы: small 10, medium 14, large 20, xlarge 28.
- Тени: small 0 1 2 rgba(11,31,59,.06); medium 0 4 16 rgba(11,31,59,.08);
  large 0 12 32 rgba(11,31,59,.12).
- Карточка: белая, радиус 20, тень small, без рамки (рамка — только у выделенного).

## Движение

- fast 150ms, normal 220ms, slow 350ms; ease-in-out, без отскоков.
- Нажатие кнопки — масштаб 0.98.
- Заставка приложения 1.4–2.1 с: знак появляется (0–0.3), кобальтовый сегмент
  дотягивается (0.3–0.9), слово ORDA / CONTROL / слоган (0.9–1.45), переход в
  интерфейс без жёсткой склейки (1.45–2.1).
